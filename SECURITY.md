# Security policy

## Reporting a vulnerability

Please report security issues privately through the contact form at https://isgenai.com/contact rather than opening a public issue. Include:

- the affected component (`packages/file-evidence` or `extension/`) and version or commit;
- steps or a file that reproduces the problem;
- the impact you observed.

We aim to acknowledge reports within a few working days and will let you know when a fix is released.

## Scope

In scope: crashes, hangs or excessive memory use when parsing crafted files; parsing that returns a record from corrupt or ambiguous input; extension issues such as permission misuse or content-script injection.

The hosted service at isgenai.com is covered by the same contact address.

## Supported versions

Only the latest commit on `main` and the latest published extension version receive fixes.
